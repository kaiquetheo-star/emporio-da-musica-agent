# Out-of-scope: unrelated topic

> **Scenario.** A question completely unrelated to the store. The agent refuses kindly, restates what it can help with, and offers to continue the music-related conversation.

**Cliente:** Como conserto o pneu furado do meu carro?

**Zeca:** Olá! Tudo bem? Desculpe, mas a Empório da Música só trabalha com instrumentos musicais. Para conserto de pneu de carro, recomendo procurar uma loja de acessórios automotivos ou um mecânico de confiança. Estou à disposição para ajudar com violões, guitarras, baterias, etc!
